# OmniPlanner

OmniPlanner / OmniPlan AI is a desktop-first planning workspace for goals, weekly planning, habits, calendar blocks, email, reminders, and optional AI assistance.

The app is built around local app data and a local-first desktop workflow. It is an active app, not a polished public release or cloud productivity service.

## Repository Layout

This repository contains the OmniPlan AI desktop app in:

```text
omniplan-ai---executive-life-os/
```

On Windows, double-click `run.bat` to launch the app. Double-click `create-shortcut.bat` to add a desktop shortcut.

See [omniplan-ai---executive-life-os/README.md](omniplan-ai---executive-life-os/README.md) for setup and developer commands.
